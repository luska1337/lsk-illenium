# lsk-illenium

Add customizable clothing/tattoo/barber shops into your server direct from the game.

## 🔗 Links

- 📚 [illenium-appearance](https://github.com/luska1337/illenium-appearance)
  - Modified version to work with resource.
- 📚 [ox_lib](https://github.com/overextended/ox_lib/)
  - Resource dependency.
- 📚 [ox_mysql](https://github.com/overextended/oxmysql/)
  - Resource dependency.
